# 🎮 PlayLand

PlayLand es una aplicación móvil desarrollada en Kotlin utilizando Android Studio, que reúne cuatro videojuegos clásicos y divertidos en una sola app. El objetivo del proyecto es ofrecer entretenimiento sencillo y dinámico desde dispositivos Android.

---

# 📱 Videojuegos Incluidos

## 🍔 Catch Food
Juego de reflejos donde el jugador debe atrapar comida para obtener puntos y evitar perder vidas.

### Características
- Sistema de puntuación
- Aumento de dificultad progresiva
- Controles simples e intuitivos

---

## 🐦 Flappy Bird
Inspirado en el clásico juego arcade donde el jugador controla un pájaro que debe atravesar obstáculos sin chocar.

### Características
- Obstáculos dinámicos
- Sistema de récord
- Física básica y animaciones

---

## ❌⭕ Tic Tac Toe
El clásico juego de tres en raya para dos jugadores.

### Características
- Modo multijugador local
- Detección automática de ganador
- Reinicio rápido de partida

---

## 🐍 Snake
Versión clásica del juego Snake donde el jugador controla una serpiente que crece al comer comida.

### Características
- Incremento de velocidad
- Sistema de puntuación
- Fin del juego al colisionar

---

# 🛠️ Tecnologías Utilizadas

- Kotlin
- Android Studio
- XML para interfaces gráficas
- Canvas y lógica de videojuegos
- Gradle
